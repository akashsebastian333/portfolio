Why this works

  • ask.pinterest.com/api/proxy/pinterest/* forwards to the v3 API with the victim's .pinterest.com session cookie (SameSite=None, so it rides on third-party requests wherever third-party cookies are attached).
  • The proxy adds no CSRF token, no Origin/Referer validation, and accepts CORS-simple content types — the regen POST is a plain HTML-form-submittable request.
  • When callback= is present, the proxy wraps the response in a JSONP envelope with Content-Type: application/javascript — turning every authenticated read into a cross-origin-readable channel from any website.
  • MFA backup codes are one-time 2FA answers: reading them = bypassing the victim's MFA at a later login. Regenerating them = silently invalidating the codes the victim saved.
  • No password, no re-auth, and no email notification is sent for either action (verified against the account inbox).
